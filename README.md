# Truptimayee Dash — React Portfolio

Premium dark React portfolio built with Vite.

## Run locally

Requirements:
- Node.js 18+ (Node 20+ recommended)
- npm

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Personalize before publishing

Edit:

`src/data/portfolio.js`

Replace:
- `YOUR_EMAIL@example.com`
- `https://github.com/YOUR_GITHUB_USERNAME`
- project links if you add them

Add your actual PDF here:

`public/resume/Truptimayee_Dash_Resume.pdf`

The portfolio deliberately avoids unsupported claims about advanced Spring Boot, microservices, ML or production API architecture.
